== Fidelity — open postulates (trust boundaries)

Companion to `+verification/proofs/agda/Ordinal/Buchholz/Fidelity.agda+`. Open
problem *`+D-2026-06-14+`*
(`+docs/echo-types/decisions/ordinal-bh-order-type-fidelity-open.adoc+`).

=== Status (restated 2026-11-09)

The 2026-11-09 design audit found the previous specification unsatisfiable,
and it was restated the same day. The order-type claim is still *OPEN*.
Nothing here asserts that any order type is proven.

=== What the module now states

The order type of the *sound carrier*: terms satisfying `+WfAdm+`, ordered
by `+_<ᵇ²_+`. It postulates a height `+carrier-height : Ord+` and a
denotation `+⟦_⟧ : BT → Ord+` into the real Brouwer order
(`+bh-notation-from+`, `+--safe+`, `+BHTarget.agda+`) that

* *preserves* `+_<ᵇ²_+` on `+WfAdm+` terms;
* *reflects* it up to transitive closure (`+⟦s⟧ <′ ⟦t⟧ → TransClosure _<ᵇ²_ s t+`).
  No transitivity lemma for `+_<ᵇ²_+` exists, and `+_<′_+` is transitive,
  so reflecting into `+_<ᵇ²_+` itself could force a transitivity that may be
  false;
* is *strictly bounded* by the height (`+WfAdm t → ⟦t⟧ <′ carrier-height+`);
* is *cofinal below* the height in the non-strict sense
  (`+o <′ carrier-height → Σ t, WfAdm t × ¬ (⟦t⟧ <′ o)+`). Strict
  cofinality is unsatisfiable: `+bOmega ω+` is admissible and has no outgoing
  `+_<ᵇ²_+` edge, so the carrier has a maximum, and strict cofinality at its
  own denotation plus `+reflect+` would demand an edge out of it. (Corrected
  2026-11-09 after review on ordinal-notation#6.)

That is "the sound carrier has order type `+carrier-height+`", up to the
transitive closure. Proved for real alongside it: `+markers-≤ω+`, every
Ω-marker in a Buchholz term is `+≤Ω ω+`.

*Explicit non-claim.* This is *not* the ψ₀(Ω_ω) claim. `+_<ᵇ²_+` has no
constructor relating two ψ terms at the same index (`+<ᵇ²-ψΩ+` needs
`+μ <Ω ν+` strictly), and its ψ-headed sources must satisfy `+WfAdm+`
(`+rank-pow α <′ ω-rank-pow ν+`), which `+BH+` itself fails. So the carrier
omits the ψ₀ fragment of the Buchholz order. Identifying its height with
ψ₀(Ω_ω) needs a carrier with that fragment. `+_<ᵇʳᶠ²_+`, which adds the
same-binder `+ψα+` congruence, is the nearest candidate, and it still keeps
`+WfAdm+` on ψ sources. `+rank2+` is *not* a denotation: it is the
height-collapsing termination measure, monotone but neither reflecting nor
cofinal.

=== History: what the audit found in the previous specification

* `+cofinal : (o : 𝒪) → Σ BT (λ t → WfBT t × (o <𝒪 ⟦ t ⟧))+` at
  `+o := bh-height+` contradicted `+ordinal-upper-bound+`, so the two
  postulates derived `+⊥+` inside `+AtHeight+`. Cofinality into all of
  `+Ord+` is unsatisfiable on its own, since `+BT+` is countable.
* `+ordinal-upper-bound+` ranged over every `+WfBT+` term, including
  `+bOmega ω+`, which any faithful denotation sends above ψ₀(Ω_ω).
* `+pins-BH : ⟦ BH ⟧ ≡ bh-height+` put a carrier element *at* the height,
  which an order type equal to the height cannot have, and `+BH+` is not
  `+WfAdm+` in any case.
* The postulates sat inside a module parameterised by the height, so they
  were assumed for every `+Ord+`.

=== Discharge

When both postulates are replaced by real terms, `+order-type+` becomes a
theorem about the sound carrier. Only then may a *human* update the
decision log and roadmap from "`OPEN`", and the ψ₀(Ω_ω) identification
remains a separate open step.
