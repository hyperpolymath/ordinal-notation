[.lead]
A constructive Agda development of ordinal notations: Brouwer ordinals, the
Veblen functions up to a defined Γ₀, and a Buchholz-style term order with
machine-checked well-foundedness. It was extracted from
https://github.com/hyperpolymath/echo-types[echo-types]. Every module checked
by the gate compiles under `--safe --without-K` with no postulates.

toc::[]

== Status: frozen

This repository is the *hand-off record* of a research ladder that outgrew
echo-types. It is not an active project. The owner decision (`D-2026-06-21`,
recorded in `docs/echo-types/decisions/ordinal-fidelity-ladder-parked.adoc`)
is that the climb is not being continued. The artifact is valid and is kept as
it stood. Nothing here is claimed beyond what the proofs state.

*Order-type fidelity is OPEN.* There is no proof that the Buchholz order on
`WfBT` has order type ψ₀(Ω_ω). What is verified:

* well-foundedness of the Buchholz orders;
* a Veblen ladder up to a defined Γ₀, in which every level is a normal
  function and the fixed-point engine gives the least fixed point and is
  monotone in its function;
* one direction of Γ₀'s fixed-point property (`Γ₀-prefixed`).

The reverse direction is reduced to an explicit closure obligation
(`Γ₀-fixed-from-closure`) and is *not* proved. See
link:verification/proofs/agda/Fidelity-OPEN-postulates.adoc[Fidelity-OPEN-postulates.adoc] and
`docs/echo-types/decisions/ordinal-bh-order-type-fidelity-open.adoc`.

=== The two postulates

`verification/proofs/agda/Ordinal/Buchholz/Fidelity.agda` declares two
postulates, `denotation` and `ordinal-upper-bound`. It is the only file here
that is not `--safe`. It is *left out* of `All.agda` and is recorded as
`quarantine` in `verification/proofs/agda/MANIFEST`, so nothing verified
depends on it.

== What is here

[cols="1,3",options="header"]
|===
| Path under `verification/proofs/agda/Ordinal/` | Content

| `Brouwer/`
| Brouwer ordinals, arithmetic, ω-powers, `ω^^`, `ε₀`, Veblen `φ₁` and the
  binary `φ`, normality and monotonicity lemmas, `Γ₀` defined.

| `Buchholz/`
| The Buchholz term syntax `BT`, the partial order `_<ᵇ_` and its
  well-foundedness, the sound doubled-ladder order `_<ᵇ²_` with an
  unbudgeted `wf-<ᵇ²`, rank embeddings into Brouwer ordinals, surface,
  extended and recursive-surface orders, and the `Fidelity` scaffold.

| `CNF.agda`, `Closure.agda`, `PsiSimple.agda`, `Base.agda`, `OmegaMarkers.agda`
| The Cantor-normal-form layer, the ℕ-staged closure, the pedagogical ψ, and
  the Ω-marker leaf module.
|===

link:docs/EXPLAINME.adoc[docs/EXPLAINME.adoc] maps each claim to the module
and theorem that proves it. The Veblen levels, the doubled-ladder design and
the rejected routes are explained in `docs/bridges/buchholz-plan.adoc` and
`docs/bridges/buchholz-rank-obstruction.adoc`.

== Build

You need Agda 2.6.3 or later and version 2.3 of the Agda standard library,
registered under the library name `standard-library`.

[source,sh]
----
agda verification/proofs/agda/All.agda
----

`verification/proofs/agda/ordinal-notation.agda-lib` sets the include path. The template proof gate
checks every module listed in `verification/proofs/agda/MANIFEST`: 76 gated
modules, plus `Fidelity.agda`, which must keep failing `--safe`.

[source,sh]
----
just proof-check-agda
----

`verification/proofs/agda/Ordinal/Buchholz/Smoke.agda` pins the headline
theorems.

== Relation to echo-types

echo-types keeps three small bridge modules, because its echo-to-ordinal
bridge depends on them: `Ordinal.OmegaMarkers`, `Ordinal.Buchholz.Syntax` and
`EchoOrdinal`. The first two also live here, so the two copies can drift.
Treat the copies in this repository as the maintained versions of the ordinal
side.
