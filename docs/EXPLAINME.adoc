This file maps each claim made about this repository to the module and theorem
that carry it. It also says plainly what is *not* proved.

All paths are under `verification/proofs/agda/Ordinal/`. Every module named
here is gated in `verification/proofs/agda/MANIFEST`, is imported by
`All.agda`, and compiles under `--safe --without-K` with no postulates. The one
exception is `Buchholz/Fidelity.agda`, which is described in its own section
below.

== Brouwer ordinals and well-foundedness

Claim:: The Brouwer ordinals carry a well-founded strict order.
Carried by:: `wf-<′` in `Brouwer/Phase13.agda`.

== Ordinal exponentiation and ε₀

Claims::
* `ω^^_` raises ω to an ordinal power, including limit exponents.
* `ε₀` is defined and is an ε-number: a fixed point of `ω^^` in both `≤′`
  directions.
* `ω^^` is inflationary.
Carried by::
`ω^^_`, `ε₀`, `ε₀-ε-number` and `ω^^-infl`, all in `Brouwer/OrdinalExp.agda`.

== The Veblen hierarchy up to Γ₀

Claims::
* Every value of φ₁ is an ε-number (`φ₁-ε-number`, `Brouwer/VeblenPhi.agda`).
* `next-ε β` is the *least* ε-number above β (`next-ε-least`,
  `Brouwer/VeblenPhiNormal.agda`).
* The binary Veblen function `φ` and the diagonal `Γ₀` are defined, in
  `Brouwer/VeblenBinary.agda`.
* Every level of `φ` is monotone in its second argument and satisfies the
  Veblen recurrence (`φ-mono₂` and `φ-level-fixed-≤`,
  `Brouwer/VeblenBinaryNormal.agda`).
* `φ` takes a monotone step in its first argument, and `Γ₀ ≤′ φ_Γ₀(0)` holds
  (`φ-mono₁-step` and `Γ₀-prefixed`, `Brouwer/VeblenBinaryMono.agda`).
* The fixed-point engine gives the least fixed point (`nextFix-least`,
  `Brouwer/VeblenBinaryLeast.agda`).
* The fixed-point engine and the derivative are monotone in the iterated
  function (`nextFix-mono-in-g` and `deriv-mono-in-g`,
  `Brouwer/VeblenBinaryMonoG.agda`).

Not proved:: The reverse inequality `φ_Γ₀(0) ≤′ Γ₀`, and so the claim that Γ₀
is the least fixed point of the diagonal. `Γ₀-fixed-from-closure`
(`Brouwer/VeblenBinaryLeast.agda`) reduces it to an explicit closure
obligation, and that obligation is *open*.

Two modules are checked refutations. Each proves that a tempting lemma is
false, so the route that needs it is not tried again:
`Brouwer/StrictLeftMonoRefuted.agda` (strict left-monotonicity of `_⊕_`) and
`Brouwer/AdditivePrincipalGenericRefuted.agda` (additive principality of
generic sums).

== Buchholz terms and their orders

Claims::
* The partial Buchholz order `_<ᵇ_` on the admitted core is well-founded
  (`wf-<ᵇ`, `Buchholz/WellFounded.agda`). The proof is structural and uses no
  rank.
* The doubled-ladder order `_<ᵇ²_` is ordinally sound. The rank `rank2` is
  strictly monotone over all twelve core constructors (`rank2-mono-<ᵇ²`), so
  `_<ᵇ²_` is well-founded by transport along `rank2` (`wf-<ᵇ²`). Both are in
  `Buchholz/RankDoubledLadderUmbrella.agda`.
* The recursive surface order, restricted to the sound carrier, is
  well-founded with *no* budget (`wf-<ᵇʳᶠ²`,
  `Buchholz/RecursiveSurfaceSound.agda`).
* The budgeted recursive surface order is well-founded (`wf-<ᵇʳᶠᵇ`,
  `Buchholz/RecursiveSurfaceBudget.agda`).
* The Brouwer order and its well-foundedness are packaged as a target notation
  (`bh-notation-from`, `Buchholz/BHTarget.agda`). This fixes only the order,
  not the embedding into it.

Not proved:: Global well-foundedness of the unbudgeted recursive surface order
over the native `_<ᵇ_`. The routes tried are recorded as walled in
`docs/bridges/buchholz-rank-obstruction.adoc`. The native `_<ᵇ_` is not
ordinally sound, so no rank embedding can map it. Its well-foundedness comes
from `wf-<ᵇ` directly.

== Order-type fidelity: open, with two postulates

Claim (OPEN):: The Buchholz order on `WfBT` has order type ψ₀(Ω_ω).

`Buchholz/Fidelity.agda` states this theorem in a typed form. It assumes two
postulates:

* `denotation`, an order-preserving embedding into the target notation;
* `ordinal-upper-bound`, a bound on its image.

The candidate height is a module parameter (`Fidelity.AtHeight`), not an
axiom. The file is not `--safe`. It is left out of `All.agda` and is recorded
as `quarantine` in the MANIFEST, and the gate checks that it still fails
`--safe`.

Discharging the postulates needs the ordinal-collapsing function that would
produce the height. That function is not built. ψ₀(Ω_ω) lies far above Γ₀, so
the Veblen ladder alone does not reach it. See `verification/proofs/agda/Fidelity-OPEN-postulates.adoc`
and `docs/echo-types/decisions/ordinal-bh-order-type-fidelity-open.adoc`.

== How the checks are run

* `agda verification/proofs/agda/All.agda` checks everything that is gated.
* `just proof-check-agda` runs `scripts/check-proofs.sh agda`. It compiles each
  gated module with `--safe`, confirms that the quarantined module still fails,
  and fails if any `.agda` file is missing from the MANIFEST.
* `Buchholz/Smoke.agda` pins the headline names, so a renamed theorem breaks
  the build.

There is no CI workflow for the proofs yet. Until one exists, these checks run
locally.
