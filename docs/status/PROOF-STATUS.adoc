`verification/proofs/agda/`. It replaces the RSR template placeholder that
stood here until 2026-11-09. Status tokens are the closed vocabulary of
standards PROOF-POLICY §5 (`proven`, `proven-with-postulates`, `tested-only`,
`argued`, `open`). Grades are Proof Witness Grades (PROOF-POLICY §8).

link:../EXPLAINME.adoc[EXPLAINME] maps each claim to its module in more
detail. This repository is a frozen hand-off record (decision D-2026-06-21);
nothing here is an active climb.

== Trusted base

* The only postulates are `denotation` and `ordinal-upper-bound` in
  `Buchholz/Fidelity.agda`. That file is not `--safe`, is not imported by any
  module, and is `quarantine` in the MANIFEST.
* `scripts/check-agda-trusted-base.sh` pins exactly those two postulates and
  rejects escape pragmas. Its postulate pattern is anchored at line start,
  and its escape list omits `NON_COVERING`, `--type-in-type`,
  `--allow-unsolved-metas` and `--no-termination-check`; `--safe` covers the
  gated files regardless.

== Known gaps (2026-11-09)

* No CI job runs Agda. The checks run locally.
* `scripts/check-proofs.sh agda` uses `agda --safe`, not the PROOF-POLICY §2.1
  invocation `agda --safe --without-K --cubical-compatible`. Every gated file
  declares `--safe --without-K` in its own header.
* The quarantine check passes if `Fidelity.agda` fails `--safe` for any
  reason; it does not check that the file still type-checks without
  `--safe`.
* The Brouwer and Veblen headline names are not pinned in a Smoke module.
* Files do not yet declare the estate strict flag set (`--cubical-compatible
  --exact-split --no-sized-types --no-guardedness`); the code is compatible
  with it (#2).
